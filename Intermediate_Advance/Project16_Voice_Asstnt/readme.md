# 🎙️ ARIA - Advanced AI Voice Assistant

ARIA is a lightweight, fast, and conversational CLI BASED  AI Voice Assistant built using **Python**, **Groq Cloud API (Llama 3.1)**, and **Speech Recognition**. It listens to your voice commands, processes the input through a powerful Large Language Model (LLM), and responds back out loud with a natural-sounding voice.

---

## ✨ Features
* **Voice-to-Text (STT):** Captures your voice accurately using Google Speech Recognition.
* **Smart Brain (LLM):** Powered by Groq's ultra-fast `llama-3.1-8b-instant` model for conversational intelligence.
* **Text-to-Speech (TTS):** Speaks back dynamically using `pyttsx3` with tuned speech rates and clarity.
* **Smart Threshold Management:** Configured with manual pause and energy thresholds to prevent premature cut-offs while speaking.
* **Context Awareness:** Remembers previous messages in the current session for smooth back-and-forth dialogue.

---

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **AI Brain:** Groq API (Llama 3.1 Model)
* **Speech Modules:** `SpeechRecognition`, `pyttsx3`, `PyAudio`
